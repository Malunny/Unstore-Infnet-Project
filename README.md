
# Unstore

A Unstore é um sistema web de e-commerce/administração focada na venda materiais e equipamentos de construção, cortinas e persianas. Seu propósito é ser uma plataforma para vender tais produtos e administrá-los.




## Tecnologias utilizas 
![DOTNET](https://img.shields.io/badge/-.NET%2010-blueviolet?logo=dotnet) ![ASP.NET](https://img.shields.io/badge/ASPNET-Razor%20Pages-blueviolet)
## 🛠 Habilidades
C#, ASP.NET, Razor Pages, Auth, Authorization, HTML, CSS, Bootstrap, Frontend, Backend.


## Funcionalidades

- Listagem de produtos;
- Administração de produtos;
- Sistema de autenticação e autorização;

## Funcionalidades Futuras

- Sistema de reposição de produtos;
- Sistema de conversa com cliente;
- Entre outros;
